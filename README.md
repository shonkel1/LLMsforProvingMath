# LLMsforProvingMath
This is a project that involved the usage of Large Language Models to prove mathematical theorems with the help of finetuning and prompt construction.
This project investigates the usage of available informal proof datasets to finetune
LLMs on the task of informal proof generation. Additional objectives include using
formalisation, which is the task of converting informal proofs to formal proofs, in order to
improve informal proofs, by ways of iteratively improving and verifying the informal proof
by using an interactive theorem prover as a verifier. The interactive theorem prover in
question was the Lean theorem prover, in its latest iteration Lean 4.
